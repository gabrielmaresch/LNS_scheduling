PPO AGENT MODEL EVALUATION PLAN (ASCII VERSION)
Setup / facts (as given)
- You have 15 total instances in a fixed pool.
- You trained 5 separate PPO models.
- For each model:
  - Training set: 12 randomly chosen instances (from the 15).
  - Test set: the remaining 3 instances (held out from training for that model).
  - Evaluation on test: each of the 3 test instances is run with 20 random seeds.
Goal
1. Compare the 5 PPO models on held-out generalization.
2. Measure variance across seeds.
3. Optionally compare vs baselines (CP-SAT, ALNS variants, heuristics) if available.
4. Diagnose policy behavior (action usage, state visitation, failure modes, learning stability).

Important structural issue:
Each model has different held-out test instances (because the 12/3 split is random per model).
So you must decide what "comparison" means. Do both A and B below.
Task 6A - Comparison on each model's own held-out test set (within-model evaluation)
For each model m, define its held-out score as an aggregate over its 3 test instances:
Option 1 (mean-of-means):
score_mean(m) = mean over i in Test(m) of mean_objective(m,i)

Option 2 (median-of-means):
score_median(m) = median over i in Test(m) of mean_objective(m,i)
Option 3 (robust worst-case):
score_worstcase(m) = max over i in Test(m) of mean_objective(m,i)
Also compute corresponding std across the 3 test instances to reflect heterogeneity.
Deliverable:
One table with 5 rows (one per model) and the three scores above.
